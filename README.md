# SLVY Projetos — Protótipo de Website

Protótipo de um site institucional para apresentar uma proposta visual à SLVY Projetos, com foco em reformas em Curitiba e região.

> Este projeto é uma demonstração independente e não oficial. Não representa um site aprovado ou contratado pela SLVY Projetos.

## Objetivo

Demonstrar como um site pode apresentar os serviços da empresa, fortalecer sua presença digital e facilitar solicitações de orçamento.

## Funcionalidades

- Layout adaptado para celulares e computadores.
- Apresentação dos serviços.
- Explicação das etapas para solicitar um orçamento.
- Link para o Instagram da empresa.
- Formulário demonstrativo que prepara uma mensagem para copiar.

O formulário não envia informações à empresa e não possui integração com um servidor.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Imagem ilustrativa

A imagem do ambiente foi gerada por inteligência artificial exclusivamente para este conceito. Não representa uma obra realizada pela SLVY Projetos.

## Publicação

O projeto foi preparado para hospedagem estática no GitHub Pages.

## Observações

Textos, identidade visual, serviços e informações comerciais estão sujeitos à revisão e aprovação da empresa antes de qualquer uso oficial.

Não inclui depoimentos, resultados ou obras atribuídos à empresa sem comprovação.
